Project Overview

This project studies ensemble learning techniques and model generalization using the Breast Cancer Wisconsin dataset. Different machine learning models are trained and their training and testing performance is compared to understand overfitting, underfitting and generalization.

```
```

Bagging

Bagging trains multiple models independently on different samples of the dataset and combines their predictions. Random Forest is a popular bagging algorithm.

```
```

Boosting

Boosting builds models sequentially. Each new model attempts to improve the errors made by previous models. XGBoost and LightGBM are popular boosting methods.

```
```

Bias-Variance Trade-off

High bias generally indicates that a model is too simple and may underfit. High variance generally indicates that a model is too sensitive to training data and may overfit.

```
```

Regularization

Regularization adds a penalty to model complexity. L1 can encourage some coefficients to become zero, while L2 generally shrinks coefficients toward zero.

L1 vs L2 Regularization

L1 Regularization

L1 adds an absolute-value penalty to model coefficients. It can drive some coefficients exactly to zero, which can perform feature selection.

L2 Regularization

L2 adds a squared penalty to coefficients. It generally keeps coefficients small instead of eliminating them completely.

What We Learned

  • Bagging reduces variance by combining multiple models.
  • Random Forest is an example of a bagging ensemble.
  • Boosting builds models sequentially to improve predictions.
  • XGBoost and LightGBM are gradient boosting algorithms.
  • High bias can result in underfitting.
  • High variance can result in overfitting.
  • L1 and L2 regularization help control model complexity.
  • Testing performance is important for measuring generalization to unseen data.
