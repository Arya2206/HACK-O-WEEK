Understanding Dimensionality Reduction

What is Dimensionality Reduction?

Dimensionality reduction is the process of reducing the number of features in a dataset while trying to preserve important information. It is useful for visualization, noise reduction, faster computation and understanding complex datasets.

PCA

Principal Component Analysis transforms the original features into new directions called principal components. The first component captures the maximum variance, while the second captures the next highest variance.

t-SNE

t-SNE is mainly used for visualization. It attempts to keep similar data points close together and dissimilar points farther apart in a lower-dimensional representation.

Dataset

This project uses the Iris dataset containing 150 samples and 4 numerical features.

  • Sepal Length
  • Sepal Width
  • Petal Length
  • Petal Width

PCA Visualization

PCA reduces the original 4-dimensional dataset to 2 principal components.


t-SNE Visualization

t-SNE maps the four-dimensional data into two dimensions while trying to preserve local relationships between similar samples.


PCA vs t-SNE

  • PCA is a linear dimensionality reduction technique.
  • t-SNE is a nonlinear technique mainly used for visualization.
  • PCA preserves directions of maximum variance.
  • t-SNE focuses on preserving local neighborhood relationships.
  • PCA is generally faster and easier to interpret.
  • t-SNE can reveal clusters that may not be obvious in the original high-dimensional space.
